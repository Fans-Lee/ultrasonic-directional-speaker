# ESP32-S3 120 阵元单 GPIO 正式固件

本工程对应 `docs/09-当前120阵元单GPIO接线.md` 定义的比赛整机：GPIO4 经 4 片 SN74HC125N 两级扇出为 12 路，再由 12 片 TC4428A 分别驱动 10 只并联的 TCT40-16T，共 120 只换能器。

它从 `esp32_s3_4x3_min_test` 提取已经验证的音频、调制和定时部分，并删除 4×3 原型专用的四通道控制。这里的“12 路”是外部硬件功率支路，不是 12 个软件相位通道；全部支路接收同一个 GPIO4 波形。

## 1. 工程边界

本固件负责：

- GPIO4 上的 38～42 kHz 单路载波；
- 固定载波、20～3000 Hz 包络测试和 Flash PCM 播放；
- DSB-AM / SRAM 调制；
- RAW / LOUD 音频电平处理；
- STANDARD / BOOST 包络深度；
- 8 kHz GPTimer 调度、过期样本跳过和时序警告；
- GPIO6左右、GPIO5上下的MG996R二维云台控制；
- 上电回到逻辑`(0,0)`并循环播放内置音频；
- 运行错误停止超声切换。

本固件不负责：

- GPIO5～GPIO7的超声逐组输出；
- 电子相位转向、聚焦和逐组增益；
- 摄像头、目标识别和PC视觉；
- 云台机械限位、零点偏置和视觉闭环标定；
- 切断12 V功率电源。

摄像头和PC视觉仍属于独立控制链；它们通过串口向本固件发送`(左右,上下)`目标角度。本版冻结GPIO6为左右、GPIO5为上下，两轴逻辑范围均为-90°～90°，但机械限位、实际零位和方向仍须在装机后标定。

## 3. 与最小测试相比删除的内容

以下4×3原型遗留没有进入本工程：

- `kChannelCount = 4`和GPIO4/5/6/7数组；
- `setChannelDuty()`、`setAllDuty()`和四路更新循环；
- `1～4`单独选列命令；
- `CH1～CH4`、`four columns`和`4x3 smoke test`提示；
- 四路更新同步性的无效负担；
- `audio_data.h`无真实PCM时生成八音旋律的回退分支。

保留的内容都有120阵元用途：载波调谐、纯音测试、PCM播放、DSB/SRAM、RAW/LOUD、STANDARD/BOOST、中心对齐PWM和积压处理。

## 4. 信号与功率路径

```text
audio_data.h / 测试正弦
        ↓ 8 kHz
调制包络 → 反正弦映射 → LEDC duty + hpoint
        ↓
GPIO4：默认40 kHz、10-bit、中心对齐PWM
        ↓
U0 → U1/U2/U3：12路同相3.3 V逻辑
        ↓
P1～P12：TC4428A互补差分输出
        ↓
12组 × 10只并联TCT40-16T
```

GPIO4只传递时序；SN74HC125由3.3 V供电；阵列能量来自12 V功率电源。完整逐针接线和上电顺序以 `../../docs/09-当前120阵元单GPIO接线.md` 为准。

## 5. 串口命令

串口为115200波特率，字母命令不需要回车，数字命令需要回车或空格结束。

| 命令 | 功能 |
|---|---|
| `0` + 回车 | 停止GPIO4切换 |
| `A` | 完整阵列固定载波，50%占空比 |
| `T` | 1 kHz包络测试 |
| `20`～`3000` + 回车 | 指定可听测试频率 |
| `D` / `S` | 下一次PCM使用DSB-AM / SRAM |
| `R` / `E` | 下一次PCM使用RAW / LOUD处理 |
| `N` / `B` | 下一次纯音或PCM使用STANDARD / BOOST包络 |
| `-`、`[` | 载波降低100 Hz，最低38 kHz |
| `+`、`]` | 载波提高100 Hz，最高42 kHz |
| `C` | 恢复40 kHz |
| `F` | 打印实际载波频率 |
| `P` / `L` | PCM播放一次 / 循环播放 |
| `(左右,上下)` | 设置云台逻辑角度，例如`(-10,30)`；两轴范围均为-90°～90° |
| `H` / `?` | 打印帮助 |

`D/S/R/E/N/B`只选择下一次播放参数，不会改变正在运行的PCM或纯音。

## 6. 调制参数

音频样本归一化为：

```text
s = (sample - 128) / 128
```

调制公式：

```text
DSB-AM: E = b + d·s
SRAM:   E = sqrt((b+d)·(b+d·s))
PWM:    duty_ratio = asin(E) / π
```

| 驱动模式 | `b` | `d` | DSB理论包络范围 |
|---|---:|---:|---:|
| STANDARD | 0.45 | 0.40 | 0.05～0.85 |
| BOOST | 0.50 | 0.48 | 0.02～0.98 |

LEDC周期为1024 counts，最大duty为512。驱动层设置：

```text
hpoint = (1024-duty)/2
```

使脉冲中心尽量固定，降低改变占空比时产生的附加相位调制。

## 7. 更换Flash音频

在仓库根目录执行：

```powershell
py .\utils\wav_to_audio_header.py `
  .\input.wav `
  .\src\full_size\src\data\audio_data.h
```

转换器接受最长30秒的未压缩PCM WAV，并进行单声道合并、8 kHz重采样、去直流、峰值归一化和首尾淡入淡出。生成后需要重新编译和烧录。

## 8. 烧录设置

Arduino IDE建议：

- Board：`ESP32S3 Dev Module`；
- Upload Speed：`115200`；
- Flash Size：`16MB`；
- PSRAM：按ESP32-S3-WROOM-1-N16R8实际配置选择8MB OPI；
- USB CDC On Boot：按当前CH340X烧录链路选择`Disabled`；
- 串口监视器：115200波特率。

打开 `full_size.ino` 编译和烧录。上电后云台回到`(0,0)`，内置音频自动循环。

舵机不能由ESP32的3.3V脚供电。MG996R使用独立5～6V大电流电源，两个舵机电源地与ESP32的PUBLIC GND共地；GPIO6只接左右舵机信号，GPIO5只接上下舵机信号。

## 9. 首次上电顺序

1. 不插TC4428、不接换能器，检查12 V、3.3 V和GND无短路。
2. 只给SN74HC125上3.3 V，发送`A`，确认12路逻辑输出同相。
3. 暂不接换能器，每次只插一片TC4428，检查OUT_A和OUT_B互补。
4. 先给一片TC4428接1只换能器，再扩到该组10只。
5. 单组通过后逐组增加，最后才连接120只。
6. 首次满阵播放使用STANDARD和RAW，短时间运行并记录电流、波形和温升。
7. 基线通过后再比较LOUD、BOOST和SRAM。

普通示波器测差分输出时，两个探头地夹都接PUBLIC GND，再用数学通道计算`CH1-CH2`。禁止把地夹接到TC4428的pin 5或pin 7。

## 10. 安全边界

- 串口`0`只停止40 kHz切换，不会断开12 V。
- TC4428输入静止时，两个输出仍可能一高一低。
- 改线、插拔芯片和连接示波器前必须物理断开12 V。
- 不把耳朵靠近阵面，不用手机分贝App判断40 kHz暴露安全。
- 120阵元必须从单片、单只负载逐步扩展，不能第一次上电就接满阵列。
- 本固件不能代替保险丝、总开关、星形配电、温升监测和合格的超声测量。

## 11. 当前音频链的已知限制

- PCM为8 kHz、8-bit、单声道，理论音频上限低于4 kHz；
- Flash逐样本读取，没有实时音频输入和DMA；
- GPTimer调制更新没有与LEDC载波边界硬件锁存；
- PWM占空比调制可能产生非定向的机械可听泄漏；
- DSB-AM和SRAM的实际失真必须在相同可听基波声压下测量；
- 手机麦克风不能证明40 kHz声压或定向可听声性能。
