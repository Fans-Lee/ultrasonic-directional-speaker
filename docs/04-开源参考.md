# 04 · 参考资料、证据等级与复用边界

> 版本：v2.0
> 日期：2026-09-13

本文件说明当前 120 阵元机械转向系统应使用哪些资料，以及哪些结论必须由本机实测产生。它不是购物链接或开源代码收藏夹。

## 1. 证据等级

| 等级 | 资料 | 可支持的结论 |
|---|---|---|
| A | 同行评议论文、政府或国际安全机构资料 | 原理、已知方法、安全背景 |
| B | 芯片制造商数据手册和官方软件文档 | 引脚、电气额定值、API 和外设行为 |
| C | 本项目可复现源码、自动测试和原始测量 | 当前实现、协议一致性和实机性能 |
| D | 开源项目、论坛、博客和商品页 | 实现线索、采购候选和排错思路 |

优先级为 `本项目实测/源码 + 官方资料 > 论文综述 > 第三方实现 > 商品描述`。低等级资料不能覆盖官方额定值，也不能替代本机波形、温升和声场记录。

## 2. 参量阵原理与调制

- [Pompei：The Use of Airborne Ultrasonics for Generating Audible Sound Beams](https://aes.org/publications/elibrary-page/?id=12092)
- [Gan、Yang、Kamakura：A review of parametric acoustic array in air](https://doi.org/10.1016/j.apacoust.2012.04.001)
- [Experimental Evaluation of Distortion in Amplitude Modulation Techniques for Parametric Loudspeakers](https://doi.org/10.3390/app10062070)

这些资料可用于解释空气非线性、自解调、调制失真和测量方法，但不能直接证明本项目已经达到某个声压、失真或覆盖角。

本项目当前实现 DSB-AM 和平方根幅度调制 SRAM。任何“SRAM 一定更清楚”或“失真降低到某个百分比”的结论都必须在相同可听基波声压、相同测点和相同分析带宽下实测。

## 3. 当前硬件资料

### 3.1 TC4428A

- [Microchip TC4428A 产品页](https://www.microchip.com/en-us/product/TC4428A)
- [TC4426A/TC4427A/TC4428A 数据手册](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/TC4426A-TC4427A-TC4428A-1.5A-Dual-High-Speed-Power-MOSFET-Drivers-20001423.pdf)

施工前必须从官方手册核对封装、引脚、供电范围、输入门限、输出结构、去耦和热特性。峰值输出电流不能解释为对任意容性负载的连续安全电流。

### 3.2 SN74HC125

- [Texas Instruments SN74HC125 产品页](https://www.ti.com/product/SN74HC125)

当前整机使用 3.3 V 供电的 `SN74HC125N`，不是旧方案中的 5 V `74AHCT125`。器件后缀、封装和厂商不同时，应重新核对引脚和电气参数。

### 3.3 TCT40-16T

- [TCT40-16T/R 通用数据表](https://cdn.sparkfun.com/assets/7/2/0/2/0/TCT40-16-T-R.pdf)

不同卖家和批次可能不是同一制造来源。40 kHz 标称频率、静电电容和灵敏度只能作为抽检起点；120 只阵元应记录批次，并抽测谐振峰、幅值和相位一致性。

## 5. 桌面软件资料

当前桌面实现依赖 PySide6、OpenCV、Ultralytics、PyTorch、sounddevice/PortAudio 和可选 OpenVINO。依赖版本以 `pyproject.toml` 和 `uv.lock` 为准，运行方式以根 README 为准。

第三方库文档可用于确认 API，但项目行为应以以下文件为准：

- `src/vision_gimbal/bootstrap.py`：实际装配关系；
- `configs/vision_gimbal.toml`：当前运行参数；
- `src/vision_gimbal/protocol/`：电脑端协议实现；
- `src/full_size/src/protocol/`：固件端协议实现；
- `tests/`：可重复的软件回归验证。

## 6. 可借鉴但不属于当前方案的项目

- [SonicSurface](https://github.com/upnalab/SonicSurface)
- [Ultraino](https://github.com/asiermarzo/Ultraino)

它们可用于理解声场仿真、相位控制、换能器标定和阵列工具链，但当前项目没有采用其多通道相控硬件。不得直接复制其相位表、阵元坐标、通道映射或安全参数。

以下内容属于未来研究，不得写成当前能力：

- 逐通道相位控制；
- 电子波束转向；
- 有限距离聚焦；
- 三维阵元标定和幅相补偿。

## 7. 安全资料

- [ICNIRP：Airborne Ultrasound](https://www.icnirp.org/en/frequencies/ultrasound/index.html)
- [Health Canada Safety Code 24](https://www.canada.ca/en/health-canada/services/environmental-workplace-health/reports-publications/radiation/guidelines-safe-use-ultrasound-part-industrial-commercial-applications-safety-code-24.html)

安全资料用于制定保守的测量和暴露控制流程。不能因为 40 kHz 通常听不到，就把设备视为无需管理；也不能使用手机分贝 App 代替具有合适带宽、动态范围和校准记录的仪器。

## 8. 本项目证据

| 结论 | 首选证据 |
|---|---|
| GPIO4 频率、占空比和停止行为 | 示波器原始波形 |
| 12 路同相程度 | 同触发条件下的多路逻辑/示波器记录 |
| 传输稳定性 | STATUS 计数和带时间戳的 JSONL 日志 |
| 电脑端协议字段和行为 | `tests/test_device_protocol.py` |
| 电脑与固件跨语言布局 | 受版本控制的 C++ 测试桩或板上抓包；当前需单独验证 |
| 音频预处理 | 输入/输出 WAV、配置和频谱数据 |
| 方向性 | 固定距离、固定增益的角度扫描原始数据 |
| 可听失真 | 相同声压条件下的录音和频谱/THD 分析 |
| 安全 | 合适仪器在人员耳位的分频带测量和保守操作记录 |

`output/` 和 `work/` 中的本机文件可以用于排错，但若要作为正式证据，必须同时记录固件提交、配置、串口、硬件接线、测量时间和仪器信息，并移入受版本控制的证据目录。

## 9. 引用与复用检查表

引用外部资料前确认：

1. 资料是否直接对应当前器件型号、封装和供电条件；
2. 结论是论文/手册原文、工程推断，还是本项目实测；
3. 第三方项目是否使用了不同阵元、频率、通道数或驱动拓扑；
4. 数字是否带单位、测量条件、日期和来源；
5. 是否把未来功能误写成当前能力；
6. 是否保留了本项目原始数据和复现实验步骤。
