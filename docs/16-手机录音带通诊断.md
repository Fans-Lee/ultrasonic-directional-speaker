# 手机录音 250–3000 Hz 带通诊断

独立入口：`utils/audio_calibration/bandpass_wav.py`。它不依赖 Qt、声卡或固件，也不修改原始录音。使用项目已有的 `uv` 环境和 NumPy：

```powershell
uv sync --locked --python 3.11
uv run python .\utils\audio_calibration\bandpass_wav.py `
  ".\data\nevergonnagiveyouup\20260921_220048.wav" `
  ".\output\audio_calibration\phone_250_3000.wav"
```

输出是与输入采样率、声道数、时长相同的 24-bit PCM WAV，另有 `phone_250_3000.report.json`，列出过滤前后全带、250–3000 Hz 与 8–17 kHz 的 RMS 电平，以及逐声道峰值和 RMS。默认保持原始增益，不自动归一化。可分别聆听原始与滤波结果；比对频谱图时需固定相同色标，不能直接比较自动色标下的颜色。

参数：

| 参数 | 默认 | 含义 |
|---|---:|---|
| `--low-hz` | 250 | 下边界 |
| `--high-hz` | 3000 | 上边界 |
| `--transition-hz` | 50 | 通带内两侧各 50 Hz 的余弦过渡；完整增益区间为 300–2950 Hz。设为 0 可硬切，但可能出现较强振铃。 |
| `--edge-fade-ms` | 10 | 录音首尾淡入淡出，减轻 FFT 的首尾环绕振铃；设为 0 可关闭 |
| `--gain-db` | 0 | 固定输出增益；只在试听音量确实不足时调整，报告保留该数值 |
| `--channel` | `preserve` | 保留原声道，或选 `left`、`right`、`mono`；`mono` 会平均所有声道 |
| `--no-report` | 关闭 | 只写 WAV，不写 JSON 报告 |

例如关闭首尾淡化并使用严格频率边界：

```powershell
uv run python .\utils\audio_calibration\bandpass_wav.py input.wav output.wav --transition-hz 0 --edge-fade-ms 0
```

本项目示例手机 WAV 的两个声道幅度相差很大。若要只听主声道：

```powershell
uv run python .\utils\audio_calibration\bandpass_wav.py `
  ".\data\nevergonnagiveyouup\20260921_220048.wav" `
  ".\output\audio_calibration\phone_right_250_3000.wav" `
  --channel right
```

这是离线零相位频域滤波器。频域掩膜在 250 Hz 以下和 3000 Hz 以上严格为零；24-bit PCM 量化会留下很低的量化噪声。非零过渡完全位于指定频段**以内**。突变处仍可能有振铃，特别是硬切模式。

若带通后杂波明显减轻，说明带外成分影响了录音试听。若仍有异常，则可能是**已在 250–3000 Hz 的伪声**；它可能来自空气中的真实失真，也可能由手机麦克风在接收超声时产生。这个数字滤波器作用在手机录音之后，不能消除已进入带内的伪声，也不能单凭滤波结果区分两个来源。建议继续比较关闭 PWM、纯载波、PCM 单音和另一套录音设备的结果。
