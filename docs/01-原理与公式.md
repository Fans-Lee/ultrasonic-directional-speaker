# 01 · 当前系统的原理、公式与能力边界

> 版本：v2.0
> 日期：2026-09-13
> 适用基线：120 阵元、GPIO4 单相位输出、机械云台转向

本章只解释当前已实现系统。电子相位转向、逐阵元控制和定点聚焦属于未来研究，不是当前功能。

## 1. 从音频到定向可听声

当前数据链为：

```text
可听基带音频
→ 幅度包络
→ 40 kHz PWM 载波
→ 120 个换能器同相辐射
→ 空气非线性产生可听差频
```

可听声不是 ESP32 直接输出的普通扬声器波形。ESP32 只生成超声载波及其包络，可听成分主要由空气传播中的非线性产生。

常用的 Berktay 远场近似可写为：

```text
p_audio(t) ∝ d²(E²(t)) / dt²
```

`E(t)` 是超声包络。这个近似用来理解预处理和失真趋势，不能单独预测实际响度、安全声压或房间中的完整声场。

## 2. 40 kHz 和阵面尺寸

声速取 `c ≈ 343 m/s`、载波 `f_c = 40 kHz`时：

```text
λ = c / f_c ≈ 343 / 40000 ≈ 8.6 mm
```

当前阵面口径约 23 cm，明显大于超声波长，因而同相阵列能在正前方形成比同尺寸普通可听声扬声器更窄的主瓣。

若把阵面粗略视为均匀圆形口径，第一零点半角可用下式作数量级估算：

```text
θ_null ≈ 1.22 · λ / D
```

该结果是理想口径估算。实际结果还受换能器间距、单元方向性、幅相误差、阵面孔洞、安装结构和反射影响。文档和答辩不得把该估算写成已测方向角。

## 3. 当前调制公式

8-bit 无符号 PCM 样本先归一化：

```text
s = (sample - 128) / 128
```

固件提供两种包络：

```text
DSB-AM: E = b + d·s
SRAM:   E = sqrt((b+d)·(b+d·s))
```

这里的 SRAM 是 Square-Root Amplitude Modulation，不是 ESP32 存储器。

| 驱动档位 | `b` | `d` | DSB 包络范围 |
|---|---:|---:|---:|
| STANDARD | 0.45 | 0.40 | 0.05～0.85 |
| BOOST | 0.50 | 0.48 | 0.02～0.98 |

`BOOST` 会增大平均超声输出和器件压力，不能因为它没有提高 12 V 电源电压就将其视为无风险。首次硬件试验使用 `RAW + STANDARD + DSB-AM`。

## 4. 包络到 PWM

对单极性方波，基波幅值与 `sin(πD)` 近似成正比。固件用反正弦查表把包络换成占空比：

```text
D = asin(E) / π
duty = round(1024 · D)
```

10-bit LEDC 周期为 1024 counts，当前最大 duty 限制为 512。驱动层同时设置：

```text
hpoint = (1024 - duty) / 2
```

这使脉冲尽量围绕周期中心对称，减少只移动一条边沿造成的附加相位调制。它不等于已经消除 AM–PM 耦合，最终仍需示波器验证。

## 5. 时间基准和带宽

- 超声载波默认 40 kHz，可在 38～42 kHz 之间以 100 Hz 步进调整；
- 音频更新率固定为 8 kHz，样本周期 125 µs；
- 40 kHz 载波周期约 25 µs，一个音频样本约覆盖 5 个载波周期；
- 8 kHz 采样率的 Nyquist 上限是 4 kHz，当前电脑端低通约为 3 kHz。

固件使用 40 MHz GPTimer 产生 8 kHz 节拍，但 LEDC 更新没有与 40 kHz 载波边界做硬件锁存。因此仍需检查更新抖动、过期样本跳过和可听杂音。

## 6. 方向控制的真实边界

当前 120 个阵元全部接收同一个 GPIO4 波形：

- 没有逐组相位表；
- 没有电子波束转向；
- 没有距离维度的定点聚焦；
- 没有逐组增益或相位校准。

波束在阵面坐标中始终指向法向，系统通过水平/俯仰舵机旋转整个阵面。摄像头、YOLO 和 PI 控制的任务是将这个阵面法向指向选定人体，而不是计算电子相位。

## 7. 声压、响度和测量

声压级定义为：

```text
L_p = 20 log10(p_rms / 20 µPa)
```

注意以下区分：

- `dBFS` 是数字音频相对满量程，不是 dB SPL；
- 电脑端频谱显示的是 8 kHz 基带音频，不是 40 kHz 超声频谱；
- 手机麦克风、自动增益和分贝 App 不能用来校准 40 kHz 声压；
- 定向性必须在固定距离下测方向扫描，不能只比较两个随意点。

## 8. 理论、仿真和实测的标记

| 标记 | 含义 | 可否当作项目成绩 |
|---|---|---|
| `THEORY` | 公式或理想假设 | 否 |
| `SIMULATION` | 根据模型计算 | 否，必须说明假设 |
| `TARGET` | 待验收指标 | 否 |
| `MEASURED` | 仪器、工况、原始数据可追溯 | 是 |
