# 视觉云台跟踪系统

当前闭环为：

```text
YOLO人体检测 → ByteTrack ID → Kalman瞄准点
→ 稳定目标选择 → 像素偏差转角度 → 双轴PI
→ Python后台串口 → ESP32 `(pan,tilt)` → 云台
```

## 运行

先同步Python依赖。只观察算法、不连接云台：

```powershell
uv run python .\src\cv_test\yolo_test.py
```

连接ESP32，例如串口为`COM5`：

```powershell
uv run python .\src\cv_test\yolo_test.py --serial-port COM5
```

波特率默认115200，与`src/full_size/full_size.ino`一致。程序按不高于10 Hz发送绝对整数角度，串口断开时后台自动重连，不阻塞YOLO。

## 操作与标定

- `q`：退出；`r`：释放当前目标并重新选择。
- 黄色框表示当前锁定目标，红色十字表示阵列瞄准点。
- 当前装机配置已将视觉水平轴反向；垂直轴方向保持不变。
- 首次装机必须校准水平/垂直视场角、瞄准点偏移、两轴方向和机械限位。
- PI默认参数偏保守；先只调`Kp`，稳定后再小幅增加`Ki`。舵机堵转或供电不足不能通过PID解决。
- 不配置`--serial-port`时仍会完整运行控制计算，但不会驱动硬件。

主要配置位于`yolo_tracking_app.py`、`tracking_controller.py`、`camera_geometry.py`和`visual_servo.py`。实时麦克风音频尚未接入；跟踪控制已通过独立串口接口隔离，后续可替换为音频/控制复用传输层。
