# 时不变音频辨识与预失真实验方案

日期：2026-09-21。状态：实验设计，尚无配对声学测量、拟合结果或已验证补偿器。本文不修改现有播放配置。

## 1. 目标与边界

在固定位置、固定调制和驱动档位、固定输入范围下，辨识一个参数不随时间更新的非线性模型，再离线计算预失真 PCM，使实测声音接近目标。

- 第一版目标频带：250–3000 Hz；这是项目当前的设计工作带宽，最终应根据实测信噪比和可逆性收窄。
- 固件输入：8000 Hz、单声道 PCM_U8，静音码 128。
- 声学采集：独立麦克风，优先 48000 Hz、24 bit PCM；设备只有 16 bit 时亦可先验证。
- 模型拟合、补偿后的主要误差在工作频带内计算；原始 48 kHz 录音保留，用来检查带外失真。
- 固定设置建议 RAW + STANDARD。DSB 和 SRAM 用相同 PCM 做短预实验，再选一个作为主实验模式；不预先假定 SRAM 实测一定更好。
- BOOST 若实际需要，作为独立实验配置重新辨识。不同模式的数据不能不加区分地混合拟合。
- 不建模云台运动、位置变化、温漂过程和自适应参数更新。用重复测量检验这项简化是否成立。

时不变只表示把输入延迟，输出也相应延迟；不表示线性，也不表示没有记忆。固定 FIR 和固定非线性都允许存在。

## 2. 系统边界与当前项目的注意事项

辨识对象：实际发送的 PCM 字节 → 固件调制/驱动 → 换能器/空气/固定位置房间响应 → 麦克风测得的音频。

没有校准麦克风时，输出单位为固定录音增益下的数字幅度，不能称为绝对声压 Pa 或声压级。麦克风频响会成为端到端模型的一部分。

当前代码事实：

1. `configs/vision_gimbal.toml` 的播放设置是 loud、boost=true、dsb_am；模型实验必须显式指定设置。
2. `AudioPreprocessor` 始终串接慢速电平器及压缩限幅器。固件 RAW 不会旁路这些电脑端处理。辨识优先直接发送预先生成的 PCM。
3. `utils/audio_stream_probe.py` 可直接发送头文件中的 PCM 字节、指定 raw/standard/dsb 或 sram，并保存传输日志，可复用为实验发送端。
4. `utils/wav_to_audio_header.py` 的 `convert()` 会逐文件去直流、峰值归一化至约 90%、淡入淡出，且量化比例与实时量化器略有不同。不能直接用该转换流程制作保幅度的多电平实验；可以复用只负责写头文件的 `write_header()`。
5. 内置纯音 `envelope_modulator.cpp` 的 STANDARD 偏置为 0.55，而 PCM `audio_modulator.cpp` 为 0.45；内置纯音也不经过同一套 PCM 调制选择。所有辨识和验收纯音均生成 PCM 并走实际 PCM 播放路径。
6. `PostLimiterWavRecorder` 保存的是发送前的数字监听信号，不是麦克风录到的阵列输出，也不是精确的量化后输入。必须另存实际 PCM 字节并独立录音。

## 3. 第一版模型：线性基线与三阶并联 Hammerstein

先拟合 M1 线性 FIR，再拟合 M2 二阶、M3 三阶模型，用验证集判断增加非线性分支是否值得。

理想结构写成：

\[
\hat y[n]=c+\sum_{p=1}^{P}\sum_{k=0}^{L-1}h_p[k]\phi_p(x)[n-k],\qquad P\in\{1,2,3\}.
\]

其中一阶分支描述线性频响，二阶分支能产生二次谐波及和差频，三阶分支能描述一部分压缩和三阶互调。所有 h 在播放期间固定。

概念上 phi_1=x、phi_2=x²、phi_3=x³。但实现时不能直接在 8 kHz 下对高频输入平方/立方并把混叠当成真实声学失真。例如 2.5 kHz 的二次谐波是 5 kHz，不是 8 kHz 离散平方得到的 3 kHz。

第一版采用固定的过采样特征：

\[
z=U_6(x),\qquad \phi_p(x)=\downarrow_6\{B_{AA}[z^p]\}.
\]

- U_6：固定抗成像插值，将 x 从 8 kHz 重建至 48 kHz；不是简单复制样本。
- B_AA：固定抗混叠低通，通带覆盖 3 kHz，至 4 kHz 前有充分衰减，然后降至 8 kHz。
- 所有分支保存滤波器状态、延迟和边界约定；训练、预测、优化使用完全相同的实现。
- y 也经固定抗混叠滤波降至 8 kHz。评价时再统一选择 250–3000 Hz。
- 48 kHz 插值是基带重建的建模假设，不是 40 kHz PWM 波形仿真。它不保证完整描述真实换能器前置滤波、载波采样效应或 AM–PM 耦合。

推荐起始 P=3、L=128，即每分支 16 ms，共 384 个 FIR 系数加常数项。验证候选 L=64/128/256；脉冲响应有更长尾部时，可增加 L 或改善反射条件。固定房间的长混响不意味着系统时变，但会要求更长记忆。

该结构是简化模型，缺少一般 Volterra 模型中的 x[n-k]x[n-l]（k≠l）等独立项。若新双音预测仍明显错误，先检查对齐、混叠、测量及房间尾部，再考虑少量交叉延迟项或固定前置滤波块；不要直接认定系统一定时变。

## 4. 采集布置与重复性预实验

1. 阵列和麦克风都固定在支架上，关闭云台跟踪。先选实际使用的一个位置，例如轴上约 1 m，记录距离、角度、高度、附近反射面；该距离不是默认满足某个远场条件的声明。
2. 固定载波、供电、RAW、驱动档位、调制方式和录音增益。关掉录音端 AGC、降噪、回声消除和音效。
3. 原始录音不逐段归一化。尽量让最高测试档录音峰值留有约 6 dBFS 余量，同时低档仍具有足够信噪比；这是录音电平余量，不是声压安全阈值。
4. 测量麦克风需能在实际超声场中保持线性。ADC 前已发生的超声整流/过载不能靠录音后低通消除；若对此有疑问，先验证测量链，不把所有谐波都归因于阵列。
5. 先记录关载波的环境底噪，再记录 PCM=128、载波保持开启时的基线。二者不是同一状态。
6. 先低档播放并观察稳定性；首尾重复相同参考信号，中间每约两分钟重复一次。记录设备运行时长、温湿度（可取得时）及供电情况。
7. 若参考信号的频响、电平或失真随实验顺序显著漂移，先延长稳定时间、改善供电或缩短采集批次；不把不同工作状态硬拟合为同一个系统。

## 5. 信号与数据量

峰值候选 A=0.10、0.20、0.40、0.60，均指最终量化前归一化峰值，不是 RMS。由最低档开始；只有测量与设备运行正常才继续提高。若低档接近量化或录音噪声底，标为低置信度或调整档位，不用它强行拟合高阶分支。

量化统一用 q=clip(round(128+128x),0,255)，保存后以 x_actual=(q-128)/128 建模。由于取整，实际峰值需从字节重新计算；补偿器最终约束用允许的整数码范围表示。

| 数据类型 | 第一轮建议 | 用途 |
|---|---|---|
| 底噪/载波基线 | 各 10 s | 信噪比、固定杂音 |
| 对数扫频 | 250–3000 Hz，10 s，4 档，每档 2 次 | 工作带宽、响应趋势、延迟检查 |
| 随机相位多音 | 每段 8 s，12 个独立相位种子 × 4 档 | 主拟合数据，共 48 条 |
| 带限随机噪声 | 每段 8 s，6 个独立种子 × 4 档 | 不同幅度分布/峰均比的补充，共 24 条 |
| 双音 | 5 对 × 3 个有效档，每条有效 2 s，每次含缓入缓出 | 互调与模型泛化 |
| 单音 | 300/400/500/700/1000/1500/2000/2500 Hz，3 档，有效 2 s | 频响与谐波 |
| 自然音频 | 不同来源的语音/音乐 6–10 条，每条约 8 s | 实际内容泛化、补偿验收 |

完整初轮包含同步、间隔和重复约需 20–30 分钟，具体由参考信号与重录次数决定。先用约 2 分钟的小批次验证配对、幅度保持和日志，再录完整批次。

多音使用 1 s 为周期、FFT 整数频点，约 40–80 个覆盖目标频带的频率；相位随机，生成后检查峰均比。按预先指定的 A 整体缩放，不通过削波压低峰值。记录实际峰值、RMS、种子和全部频点。可留空部分频点观察非线性新增能量。不同档位使用同一组种子便于比较。

双音建议：(500,700)、(700,1100)、(900,1400)、(1200,1700)、(1700,2300) Hz。两音等幅，控制合成峰值；记录 f1±f2、2f1、2f2、2f1−f2、2f2−f1 等位置。重合的产物频点只统计一次，并区分噪声与真实谱线。

每条录音包含：0.5 s 载波开启基线 → 固定同步标记 → 0.5 s 间隔 → 有淡入淡出的测试信号 → 0.5 s 间隔 → 相同同步标记 → 0.5 s 尾段。间隔应根据实测衰减加长，避免标记尾声污染有效段。拟合不使用标记和启动瞬态。

## 6. 数据保存和划分

每个 take 保存：

```text
take_0001/
  input_u8.bin            # 实际发送的完整字节，包括标记和间隔
  input.wav               # 与字节完全一致的 8 kHz PCM_U8 WAV
  recorded_48k.wav        # 独立麦克风的完整原始录音
  metadata.json           # 设置、种子、音量、位置、设备、输入哈希
  stream.jsonl            # 传输/设备诊断日志
  alignment.json          # 延迟、时钟比例、有效区间、质量判定
```

metadata 至少包括：take/session ID、时间、信号族/种子、训练划分、采样率、量化公式版本、字节 SHA256、峰值/RMS、raw/standard/dsb 等模式、载波、固件版本、麦克风/声卡型号、录音增益、位置、时长、重复编号、是否为原始或补偿输入。

以完整信号种子/音源划分，建议 train/validation/test≈60/20/20。一个种子的全部音量及重复必须属于同一个集合，不能把相邻采样点或重叠窗口随机分给三个集合。单独保留未参与选模的双音、单音和自然音频作最终验收。另一天同位置重录可作额外稳定性测试。

## 7. 配对、对齐与质量门槛

电脑录音时钟与 ESP32 播放时钟独立。单次互相关只能校正偏移，长录音还要校正时钟比例。

1. 由前后标记在输入/录音中的间隔估计比例，拟合 t_record=a·t_input+b。
2. 使用带抗混叠的重采样校正 a，再通过标记模板或低档参考响应估计整数及分数延迟 b。标记输出会被系统改变，不要依赖原始标记与录音必然高度相似。
3. 对齐参数由标记/独立参考段获得；不能反复扭曲测试主体来降低模型误差。
4. 保存全部校正参数。所有模型用同一对齐；FIR 留出固定因果余量并明确移除的大延迟，避免把相位误差藏在模型外。
5. 先对齐每次重复，再决定是否平均；先平均未对齐录音会抹掉高频相位。
6. 数据分块保留输入历史；块首滤波建立过程不计损失，分块长度应明显大于模型记忆。

有效段必须无录音削波、无实际 PCM 裁剪、无传输间断。检查有效播放时间内 underrun、overrun、CRC、sequence gap、timer skip、host drop 等计数增量；启动/结束阶段单独标记，不能只看最终累计值。时钟比例校正后的中间标记或重复周期仍不对齐时，应重录/检查丢样，不能用一个固定滤波器吸收它。

报告各档信噪比；信号接近噪声底时不报告精确的微小 THD 改善。开头/结尾参考的变化需小于待证明的补偿改善，否则本轮不能支持该结论。

## 8. 最小二乘拟合

给每个 p 的特征构造延迟矩阵 Phi_p，将它们及常数列拼成 Phi。模型是对输入非线性、对待估计系数线性的，因此拟合仍是正则化线性最小二乘。

\[
\theta^*=\arg\min_\theta\sum_j\frac{w_j}{N_j}\|B(\Phi_j\theta-y_j)\|_2^2
+\sum_{p=1}^{P}\lambda_p\|h_p\|_2^2.
\]

B 为固定工作频带滤波器；它同样作用于预测和实测，不能只滤实测。N_j 是有效样本数。各音量档先等权；低信噪比样本按质量降权，不用每条录音各自归一化的方法“平衡”音量。

具体流程：

1. 只用训练集统计各特征的缩放，保留正负和幅值依赖；把同一缩放用于验证/测试。平方特征直流可用一个全训练集固定均值处理，不能逐条重新中心化。
2. 先拟合 P=1 基线，再拟合 P=2/3。
3. 候选 L=64/128/256，标准化后的正则化强度例如从 10^-6 到 1 做对数网格搜索。该数值范围只是起点，与损失归一化约定绑定。
4. 初轮各分支用相同 lambda；高阶分支不稳定时增加其正则化。常数项单独处理，避免与 DC 不可辨识。
5. 小数据可用 QR/SVD 解增广最小二乘；大数据用带正则化的 LSQR/分块算子。公式上的 (PhiᵀPhi+Lambda)^-1 不是要求显式求逆，整段长录音也不应全部展开成巨大稠密矩阵。
6. 依据验证集分档 NMSE、双音预测、自然音频预测选择最小的有效模型；不以训练误差最低作为选型理由。
7. 保存 h、P/L、全部重采样/滤波系数、特征缩放、输出单位与录音增益、对齐约定、工作模式、输入范围、训练哈希和版本。

如果 P=3 对新信号并无稳定改善，保留 P=1 或 P=2。采集设计中的高阶激励也可用于证明简单模型已经足够。

## 9. 从前向模型到预失真

先完成前向预测验证，再设计补偿；模型能拟合训练录音不代表它的逆能改善真实播放。

目标 d 是工作频带内、以同一固定录音幅度标尺表示的目标声压波形。由一个独立参考确定整体转换增益；未校准麦克风时只是相对数字标尺。不能给每个补偿结果分别拟合一个最有利增益来评分。

### 9.1 线性均衡基线

用一阶模型/低档响应 H1 设计有增益限制、带正则化的 FIR 均衡器 G，在模型的已训练输入范围内播放。复数频域起点为 G=H1*/(|H1|²+lambda(f))，实现时保留固定延迟和边界填充。不要对低响应频段硬做 1/H；必要时缩窄目标频带、降低整体目标声级。

### 9.2 第一版非线性补偿：离线优化整段 PCM

\[
x^*=\arg\min_{x\in C}\frac{\|B(F_\theta(x)-d)\|_2^2}{N}
+\alpha\frac{\|x\|_2^2}{N}
+\beta\frac{\|Dx\|_2^2}{N}.
\]

C 限定实际训练过的峰值、输入频带、RMS/峰均比范围；D 是一阶差分。beta 可从 0 开始，仅在需要抑制不必要高频时增加，避免把想保留的高频细节一起抹掉。

- x 初值为线性均衡输出；目标是固定参数系统的非线性最小二乘，不保证全局最优。
- 可用带约束梯度法或 Gauss–Newton。若实现用带限基底 x=Sa，需对重建后的 Sa 施加峰值约束；简单“低通后裁剪”会重新产生带外成分，必须迭代并检查最终约束。
- 固定目标声级。不可达时统一降低本次对照的目标声级，不用饱和输出换取数值误差降低。
- 保留模型记忆和滤波器尾部，短段先做完整离线优化；长段分块需处理历史、重叠和拼接瞬态。
- 优化时可先使用连续幅度；随后按允许整数码范围量化，再把实际量化后的 x_actual 送入模型复核，最后真实播放。
- 超出训练域或模型不确定的解不直接接受；补采该范围或降低目标。
- 8 kHz 带内模型不能证明 3 kHz 以上声学失真也下降，必须用原始 48 kHz 录音另行检查。

alpha/beta/目标声级只用验证内容选择。最终测试内容的目标波形可以送进已锁定的优化器，但其真实输出录音不能再用于调参；否则该内容已变为验证数据，需要另准备最终测试集。

第一版不要同时做实时补偿器。离线端到端有效之后，再研究固定 FIR 或较小固定预失真器的实时实现。

## 10. 测试与验收

### 10.1 前向模型是否成立

所有测试均报告分音量、分信号族结果，而不是只有一个总体平均数。

\[
NMSE=10\log_{10}\frac{\sum_n[B(y-\hat y)]^2}{\sum_n[B y]^2}.
\]

只在有效非静音段计算，越负越好。保留固定增益和相位，不单独缩放预测。另看频响偏差、谐波/互调谱线位置与幅度、残差频谱，以及重复录音之间的误差下限。

建议的初轮内部目标（非已测成绩、非行业标准）：高信噪比测试段 NMSE 约 -15 dB 或更好；非线性模型比线性基线改善至少 3 dB，且改善不是仅来自某一音量。若重复测量本身达不到这一量级，先解决测量稳定性。

### 10.2 真实补偿是否有效

锁定相同 RAW、驱动和调制，比较三组：原始输入、线性均衡、非线性预失真。随机化播放顺序，各录 3 次。

公平比较的目标是相同的可听输出电平，而不是相同输入峰值。纯音匹配基波幅度，语音/音乐用统一工作频带电平准则并报告实测差异；通过独立校准设置播放增益，不靠事后分别缩放录音掩盖差异。

| 指标 | 方法与边界 |
|---|---|
| 目标波形误差 | 对齐后的实测 y 与固定目标 d 计算带内 NMSE；共同目标、共同增益标尺 |
| 频响 | 报告目标频带幅度偏差及平坦度；不能只看一条“更平”的曲线 |
| THD | 稳态单音：sqrt(sum(Ak²,k≥2))/A1；声明统计带宽和可见阶数 |
| IMD | 对无重合的指定组合频点能量求和，除以两基波能量，再开方；列明具体频点 |
| 带外失真 | 48 kHz 原始录音检查 80–250 Hz、3–10 kHz，参考麦克风有效带宽与噪声底 |
| 噪声与电平 | 载波开启基线、录音峰值、实际 PCM 峰值/RMS、量化和传输异常 |
| 听感 | 随机标签、相近响度的 A/B，记录毛刺、沙声、齿音、清晰度 |

THD 测量去除起止瞬态，使用完整周期或窗口及谱线邻域积分。高频纯音谐波可能超出 3 kHz 或分析上限，必须标明；不能把“看不到”当成“没有”。8 bit 输入本身含量化谐波，应保存并分析其频谱，区分输入已有成分与链路新增成分。

建议验收方向：同等可听电平下，多数未见双音/单音的失真比有可重复下降（例如相对降低约 30% 作为初始目标），自然音频目标误差同步下降，且无新增明显带外杂音、削波和传输异常。报告全部频点分布及最差退化项，不只挑改善最大的一项。

## 12. 执行顺序与停止条件

1. 保幅度生成和实际 PCM 记录 → 低档短录音 → 检查传输和前后标记。
2. 小规模比较 DSB/SRAM，固定一种模式，确认重复性和可测音量范围。
3. 收集多音、多档、噪声及独立验收内容，冻结数据划分。
4. 拟合 M1/M2/M3，以验证集决定模型复杂度；前向预测不合格则不进入逆优化。
5. 先验证有限增益的线性均衡，再验证非线性离线预失真。
6. 真实重放锁定的测试内容；若只有模型预测改善、真实播放未改善，应判为补偿未验证成功。

## 13. 参考与证据边界

- [Kite、Post、Hamilton：Parametric Array in Air: Distortion Reduction by Preprocessing](https://signal.ece.utexas.edu/members/tom/papers/asa98.html)：支持包络平方的二阶导数近似及换能器带宽对平方根预处理效果的限制。
- [Gudupudi：New insights into loudspeaker nonlinearities](https://www.eurecom.fr/publication/5370)：广义多项式 Hammerstein 作为扬声器非线性辨识结构的背景；并非本阵列的实测验证。
- [Identification of a parametric loudspeaker system using an adaptive Volterra filter](https://doi.org/10.1016/j.apacoust.2012.03.007)：支持参量扬声器非线性辨识及工作条件依赖的背景；本方案不采用在线自适应参数更新。

本方案的数据量、参数搜索范围和验收阈值是针对当前项目的初始工程设计，需由真实测量修订，不是文献给出的性能保证。
