# 07 · 当前版本验收、风险、安全与演示

> 版本：v2.0
> 日期：2026-09-13
> 本文件定义“完成”的证据，不预先宣称尚未实测的性能

## 1. 版本阶梯

### V0：软件与低能量台架

- Python 依赖、测试和入口可复现；
- 摄像头和人物跟踪可在无串口模式运行；
- ESP32 上电默认静音；
- GPIO4、12 路 3.3 V 扇出和二进制协议通过；
- 不连接 12 V 功率或完整阵面。

### V1：120 阵元声学基线

- 12 片 TC4428A 逐片通过；
- 120 个换能器极性、分组和连接与文档 09 一致；
- 固定载波、测试包络和 Flash PCM 可运行；
- 完成基本方向扫描、频响和温升记录；
- 不要求电脑、摄像头或实时音频即可演示内置音频。

### V2：完整交互系统

- 共享串口同时承载云台、音频和状态；
- 麦克风、立体声混音和 WASAPI 进程回环至少各完成一次验收；
- 用户显式选人后，机械云台可跟踪目标；
- 目标丢失、串口断开和静音时行为可解释；
- 连续运行期间错误计数、温升和线束运动受控。

### V3：可选分析与未来研究

- OpenVINO 深度和相对声场属于显示功能，不参与控制；
- 电子相位转向、聚焦和逐通道校准尚未实现；
- V3 功能失败不得影响 V1/V2 的稳定演示。

## 2. 当前状态记法

每个验收项只允许使用以下状态：

| 状态 | 含义 |
|---|---|
| `NOT_RUN` | 尚未执行 |
| `PARTIAL` | 只完成部分条件或证据不完整 |
| `PASS` | 按本文件条件完成并保存证据 |
| `FAIL` | 已执行但未达到判据 |
| `BLOCKED` | 缺少仪器、器件或外部条件 |

禁止用“代码存在”“肉耳听到”或“以前好像成功过”代替 `PASS`。

## 3. 软件验收

从仓库根目录执行：

```powershell
uv sync --locked --python 3.11
uv lock --check
uv run python -m pytest -q
uv run python -m compileall -q src utils
```

还应分别验证：

- `python -m vision_gimbal --help`；
- 无串口启动；
- 指定实际 `--serial-port` 启动；
- `audio_stream_probe.py --inspect-only`；
- `wav_frequency_squared_compensation.py --help`；
- 默认配置关闭可选声场时，不要求 OpenVINO。

测试数量会随版本变化，文档不固定写死通过项数；以当前命令输出和提交记录为准。

## 4. 电气验收

### 4.1 只上 3.3 V

| 测试 | 判据 |
|---|---|
| 上电默认状态 | GPIO4 不持续切换 |
| 固定载波 | GPIO4 为目标频率，默认约 40 kHz |
| 调频 | 38～42 kHz、100 Hz 步进命令有效 |
| 第一级扇出 | U0 三路输出逻辑正确 |
| 第二级扇出 | U1～U3 共 12 路同相、幅值合理 |
| 停止 | `0` 后 GPIO4 停止切换 |

### 4.2 单片 TC4428A

1. 暂不接换能器，使用限流供电。
2. 分别测 `OUT_A`、`OUT_B` 对公共地，应为互补波形。
3. 两个示波器探头地夹都接公共地，再用数学通道计算差分。
4. 禁止把示波器地夹接到 `OUT_A` 或 `OUT_B`。
5. 接 1 只换能器短时运行，断电检查温升。
6. 逐步扩到该组 10 只并重复记录。

### 4.3 十二路和全阵

- P1～P12 单独验证，不跳过中间通道；
- 对三条功率分支分别记录压降和电流；
- 检查 12 路传播延时和同相程度；
- 先运行 `RAW + STANDARD + DSB-AM`，再比较高能量模式；
- 每增加负载或持续时间后都检查 TC4428、阻尼电阻、换能器和连接器温升。

## 5. 音频和协议验收

### 5.1 Flash 与串口对照

使用同一份 `src/full_size/src/data/audio_data.h`：

1. 播放固件内置 PCM；
2. 用 `audio_stream_probe.py` 发送同一字节；
3. 两条路径选择相同的 RAW/LOUD、STANDARD/BOOST 和 DSB-AM/SRAM；
4. 比较缓冲状态、错误计数、GPIO4 波形和可听输出。

这能隔离传输问题和前端 DSP 差异，但不能替代真实 UART、GPTimer 和声学测量。

### 5.2 实时音源

每种音源至少记录：

- `connected` 和 `status_age_ms`；
- `buffer_fill_samples`；
- `underrun`、`overrun`、`crc`、`gap`、`skip`；
- `host_drop`、采集设备和采样率；
- 处理模式、运行时间和是否同时运行视觉。

进程回环还应验证：物理扬声器静音不影响数字捕获；数字静音持续后 ESP32 PWM 停止；恢复音频后重新预缓冲。

## 6. 云台与视觉验收

1. 不装阵面或采用小角度软限位验证两个舵机方向。
2. 校准相机水平/垂直视场角、瞄准偏移和云台零点。
3. 验证 UI 点击映射与实际人物框一致。
4. 验证只有“开始追踪”后的活动目标驱动云台。
5. 自动跟踪时 WASD 不得叠加控制。
6. 目标暂时丢失时可短期保持/预测；超过释放时间后停止自动跟踪。
7. 验证全范围内线束无拉扯、夹线和结构碰撞。

UI 的指令角度不是舵机反馈。没有编码器时，不能宣称闭环控制了真实机械角度。

## 7. 声学测量

### 7.1 固定条件

每次对比固定：

- 阵面位置、高度和角度；
- 测量距离、测点间隔和房间环境；
- 载波频率、音频内容和调制模式；
- 供电电压和预热时间；
- 麦克风、前端增益、采样率和分析窗口。

### 7.2 方向扫描

在固定半径或固定平面上按等间距测点，至少保存正前方和左右两侧数据。报告应区分：

- 40 kHz 超声载波方向性；
- 自解调可听声方向性；
- 结构直接辐射或电子设备产生的非定向可听泄漏。

不能用人在不同位置的主观响度或手机 App 数字替代正式方向图。

### 7.3 频响和失真

- 使用多个可听频率或扫频，保持载波和测点不变；
- 比较 RAW/LOUD、STANDARD/BOOST、DSB-AM/SRAM 时控制可听基波声压；
- 记录基波、谐波、噪声底和可能的 40 kHz 混叠；
- 麦克风或前端自身的超声互调可能制造假可听成分，应做遮挡、断载和距离对照。

## 8. 安全边界

- 40 kHz 听不到不等于没有能量或没有风险；
- 不把耳朵、手或测量麦克风长时间贴近阵面；
- 调整接线、插拔芯片、移动探头前物理断开 12 V；
- 软件 `0`、停止音频或停止追踪都不能代替 12 V 急停；
- 舵机堵转、结构碰撞或线束缠绕时立即切断舵机电源；
- 未使用合适仪器前，不公布超声暴露安全结论。

| 风险 | 可能性 | 影响 | 监测 | 缓解/回退 |
|---|---|---|---|---|
| 换能器极性或分组错误 | 中 | 高 | 分组接收测试、方向图 | 逐组断开并重新标记 |

| UART 欠载或数据缺口 | 中 | 中 | under/gap/crc/host_drop | 排查端口、调度和队列，不盲目增益 |

| PWM 造成机械可听泄漏 | 高 | 中/高 | 遮挡和近场对照 | 降低调制度，调查替代调制后端 |
| 云台方向或零点错误 | 中 | 高 | 小角度空载测试 | 收紧软限位并重新标定 |
| 目标丢失后误跟人 | 低 | 高 | 会话和丢失测试 | 保持显式选择、超时停止策略 |
| OpenVINO/声场功能过载 | 中 | 低/中 | 推理时间和 overrun | 保持可选、关闭支路，不影响主链 |
| USB/线束被云台拉扯 | 中 | 高 | 全范围慢速运动 | 应力释放、重新布线、限制角度 |
| 超声暴露未知 | 中 | 高 | 合适频带仪器 | 缩短暴露、扩大距离、限制人员区域 |

## 10. 故障排查顺序

### 完全没有输出

1. 检查 12 V、3.3 V 和公共地。
2. 检查固件是否上电默认静音以及是否收到启动命令。
3. 测 GPIO4，再测 U0、U1～U3，最后测 TC4428。
4. 用接收换能器或示波器确认 40 kHz，不以“听不到”为结论。

### 内置音频正常、实时流异常

1. 用同一 PCM 字节和同一调制模式做串口对照。
2. 查看 buffer、under、over、crc、gap、skip 和 host_drop。
3. 分别只运行音频、只运行视觉，再运行完整系统。
4. 检查采集设备、系统回环 helper 和实际采样率。

### 有声但失真或不定向

1. 回到 `RAW + STANDARD + DSB-AM`。
2. 区分空气自解调与换能器/结构直接可听辐射。
3. 检查 GPIO4 更新抖动和电源纹波。
4. 在相同基波声压下重新比较调制方式。

### 云台行为异常

1. 断开 12 V 超声功率，保留低风险舵机测试。
2. 检查 GPIO5/6、逻辑方向、补偿和软限位。
3. 确认当前显示是指令角度而非反馈。
4. 检查目标 ID、选择状态和相机安装是否移动。

## 11. 对外表述

推荐表述：

> 当前系统使用 120 个 40 kHz 换能器同相组成参量阵，单路调制信号经缓冲器复制到 12 个功率支路。阵面方向由电脑视觉控制的二维机械云台改变。系统支持内置和实时音频，但电子相位转向、定点聚焦、声压标定和硬件急停不属于当前已实现能力。

没有对应证据时，不应声称：

- 已达到某个 dB SPL 或安全暴露等级；
- 已实现人脸识别、身份识别或自动选人；
- 已实现电子聚焦或逐阵元控制；
- 手机读数能够证明 40 kHz 声压；
- 软件停止等于切断 12 V；
- 相对声场 UI 是真实声压测量。

## 12. 现场回退

| 故障 | 回退方式 |
|---|---|
| 声场分析异常 | 关闭 `spatial_field.enabled` |
| GPU 推理异常 | 使用 CPU 或已验证的另一推理后端 |
| 视觉跟踪异常 | 停止追踪，使用 WASD 手动控制 |
| 云台异常 | 断开舵机电源，固定阵面演示 |
| 实时音频异常 | 使用 Flash PCM |
| 串口异常 | 使用固件本地字母命令 |
| BOOST/LOUD 失真或过热 | 回到 RAW + STANDARD + DSB-AM |
| 任意功率异常 | 立即物理断开 12 V |
