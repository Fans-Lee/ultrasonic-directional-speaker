## 当前实施基线（2026-08-30）

比赛整机采用正六边形蜂窝阵面，共 120 个 TCT40-16T。所有换能器使用同一 GPIO4 调制信号和同一电气相位，波束方向由二维云台机械旋转；USB 摄像头连接电脑，由电脑完成人体/人脸识别并向舵机控制程序发送目标方向。

```text
ESP32-S3 GPIO4
  → 4 片 SN74HC125N 两级扇出为 12 路
  → 12 片 TC4428AEPA
  → 每片驱动 10 只并联换能器
  → 共 120 只同相阵元
```

## 1. 项目要解决什么问题

普通扬声器会把声音扩散到较大的空间。展馆讲解、排队提示、车内分区音频和定向通知等场景，希望把声音尽可能送到指定方向或局部区域，减少对旁人的干扰。

本项目使用 40 kHz 空气耦合超声换能器阵列，把音频调制到超声载波上。高声压超声在空气中传播时发生非线性相互作用，产生可听的差频声。由于超声波长约 8.6 mm，尺寸约 23 cm 的阵面可以形成远比同尺寸普通音箱窄的超声束，生成的可听声也会继承较强的方向性。

项目的核心功能：

```text
音频 → 预处理/调制 → 功率驱动
     → 120 个超声换能器 → 空气自解调 → 定向可听声
```
附加功能：
```text
视觉识别、旋转平台和音频实时采集处理。
```
